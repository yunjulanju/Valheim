# Valheim (모작 프로젝트)

Unreal Engine 5로 제작한 **Valheim 모작 멀티플레이어 생존 게임**입니다.
온라인 세션/로비 시스템을 기반으로 멀티플레이를 지원하며, 무기 전투, 인벤토리, NPC 퀘스트 등 생존 게임의 핵심 시스템을 직접 구현했습니다.

## 주요 기능

### 멀티플레이어 세션 / 로비 시스템
- 온라인 세션 생성, 검색, 참가(Create / Find / Join Session)
- 로비에서 참가 플레이어 목록 확인 후 게임 시작
- Title → Session → Lobby → Game 레벨 흐름 설계

### 무기 시스템
- 맨손, 도끼, 활 세 가지 무기 타입 구현
- 근접/원거리 무기의 서로 다른 공격 판정 및 애니메이션 처리

### 인벤토리 시스템
- 아이템 습득, 정렬, 장착/해제
- 인벤토리 UI와 데이터 구조 연동

### NPC 퀘스트 시스템
- NPC와의 상호작용을 통한 퀘스트 수주 및 진행
- 퀘스트 상태(수주/진행/완료)에 따른 데이터 관리

### 월드 배치
- 아이템 및 오브젝트를 월드에 배치하는 시스템 구현

## 개선이 필요한 부분

프로젝트를 진행하며 파악한 한계점과 다음 개발에서 보완하고 싶은 부분입니다.

- **인벤토리 개선**: 현재 구조를 확장성 있게 리팩토링 (드래그 앤 드롭, 스택 처리 등 고도화)
- **퀘스트 시스템 개선**: 단순 수주/완료 구조에서 분기형 퀘스트, 조건부 트리거 등으로 확장
- **원거리 무기(활) 개선**: 조준/발사 로직과 피격 판정 정밀도 개선
- **무기 장착 UI 개선**: 현재 UI의 가독성과 조작 편의성 개선
- **온보딩(튜토리얼) 시스템 설계**: 별도 튜토리얼이 아닌, **퀘스트 형식으로 튜토리얼을 제공하여 유저가 자연스럽게 게임에 적응하도록 유도하는 시스템**을 설계해본 경험이 있으며, 이를 실제 구현까지 발전시키는 것이 다음 목표입니다.

## 프로젝트 구조

```
Content/
├─ Level/                     # Title, Session, Lobby, Game 등 주요 레벨
├─ Blueprints/
│  └─ Lobby/                  # BP_LobbyGM, BP_LobbyPC 등 로비 관련 블루프린트
├─ UserInterface/
│  └─ SessionWidget/          # 세션 목록, 로비 UI 위젯
Source/                       # C++ 소스
```

---

## 실행 방법

1. 저장소 클론
2. `.uproject` 파일 실행 (Unreal Engine 5.7 필요)
3. 멀티플레이 테스트 시 `Play` 옵션에서 Number of Players를 2 이상으로 설정 후 PIE 실행
